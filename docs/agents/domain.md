# Domain docs

This is a single-context repository.

## Before exploring

- Read `CONTEXT.md` at the repository root when it exists.
- Read ADRs under `docs/adr/` that concern the area being changed.
- If either location is absent, continue without treating that absence as a blocker.

## Vocabulary

Use the canonical terms defined in `CONTEXT.md`. If a needed concept is missing, avoid
inventing competing terminology; record the gap for a later domain-documentation session.

## Architectural decisions

If proposed work conflicts with an existing ADR, identify the ADR and make the conflict
explicit instead of silently overriding it.
